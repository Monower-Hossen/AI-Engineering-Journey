# Statistics & Hypothesis Testing for Machine Learning

This folder contains **comprehensive resources** for Statistics and Hypothesis Testing, essential for **Machine Learning, Data Analysis, and AI applications**.  

The folder includes **notebooks and a reference PDF** to understand **descriptive statistics, inferential statistics, and hypothesis testing techniques** used in ML.


## 📂 Notebooks & PDF Overview

| No | File | Topic | Description / Learning Focus |
|----|------|-------|------------------------------|
| 01 | `01_outliers.ipynb` | Outliers | Detecting and handling outliers in datasets to improve model accuracy. |
| 02 | `02_Ztest.ipynb` | Z-Test | Performing Z-tests for population mean comparisons, understanding standard scores. |
| 03 | `03_t-test.ipynb` | T-Test | One-sample t-test for hypothesis testing on small samples. |
| 04 | `04_two_sample_T-test.ipynb` | Two-Sample T-Test | Comparing means of two independent samples. |
| 05 | `05_ChiSquare.ipynb` | Chi-Square Test | Testing independence of categorical variables, goodness-of-fit. |
| 06 | `06_ANNOVA_test.ipynb` | ANOVA Test | Comparing means across multiple groups for statistical significance. |
| 07 | `Statistics.pdf` | Full Statistics Reference | Descriptive statistics, probability distributions, hypothesis testing, visualizations. |



## Key Concepts Covered

- **Descriptive Statistics:** Mean, median, mode, variance, standard deviation.  
- **Probability & Distributions:** Normal, Binomial, Poisson, and other key distributions.  
- **Outlier Detection:** IQR method, Z-score method, visualization techniques.  
- **Hypothesis Testing:**  
  - Z-Test & T-Test (One-sample, Two-sample)  
  - Chi-Square Test  
  - ANOVA  
- **P-values & Significance:** Understanding statistical significance and decision making.  
- **Assumptions Testing:** Normality, homoscedasticity, independence.


## Learning Outcome

By completing these notebooks and PDF, learners will be able to:

1. Detect and handle **outliers** effectively in datasets.  
2. Perform **parametric hypothesis tests** (Z-test, T-test, ANOVA).  
3. Perform **non-parametric tests** (Chi-Square) for categorical data.  
4. Understand **p-values, confidence intervals, and significance testing**.  
5. Apply statistical methods for **data analysis, ML model evaluation, and feature selection**.


This folder serves as a **research-quality reference** for Statistics and Hypothesis Testing, forming a strong foundation for **Machine Learning, Data Science, and AI workflows**.
