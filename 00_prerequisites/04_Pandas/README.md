# Pandas & Data Engineering Projects

This folder contains **hands-on Pandas notebooks, visual mind maps, and reference PDFs** covering **data manipulation, preprocessing, aggregation, and feature engineering**, forming a solid foundation for Machine Learning workflows.

The content is structured from **basic to advanced**, helping learners go from **data exploration to complex transformations**.


## 📂 Notebooks, Image & PDF Overview

| No | File | Topic | Description / Learning Focus |

| 01 | `1_Series.ipynb` | Series | Introduction to Pandas Series, indexing, slicing, and basic operations. |
| 02 | `2_DataFrames.ipynb` | DataFrames | Creating, accessing, and manipulating Pandas DataFrames. |
| 03 | `3_MissingData.ipynb` | Missing Data | Handling NaN values, imputation techniques, and data cleaning. |

## Key Concepts Covered

- **Data Structures:** Series and DataFrame manipulation.  
- **Data Cleaning:** Handling missing values, duplicates, and data inconsistencies.  
- **Merging & Joining:** Combining multiple datasets efficiently.  
- **Aggregation & Grouping:** Summarizing and analyzing data using group operations.  
- **Pivoting:** Transforming datasets for multi-dimensional analysis.  
- **Operations:** Vectorized arithmetic, string operations, conditional logic.  
- **Visualization & Mind Map:** Understanding workflow, functions, and relationships between Pandas features.  


## Learning Outcome

By completing these notebooks and reference materials, learners will be able to:

1. Perform **end-to-end data preprocessing** using Pandas.  
2. Manipulate and explore datasets efficiently for ML tasks.  
3. Handle missing, duplicate, or inconsistent data professionally.  
4. Aggregate and summarize data for **statistical analysis and feature engineering**.  
5. Apply Pandas operations in **real-world ML pipelines** with clean, structured datasets.  


This folder serves as a **research-quality reference and practical guide** for Data Engineering with Pandas, forming a strong foundation for **Machine Learning and AI projects**.
