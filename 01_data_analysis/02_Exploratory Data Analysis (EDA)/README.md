# Exploratory Data Analysis (EDA) for Machine Learning

This folder contains comprehensive resources for **Exploratory Data Analysis (EDA)**, which is a crucial step in understanding datasets before applying any Machine Learning models.  

The folder includes **theory PDF, hands-on Jupyter notebooks, and clean datasets** to practice EDA techniques on real-world examples.



## 📂 Files & Resources Overview

| No | File / Resource | Topic | Description / Learning Focus |
|----|----------------|-------|------------------------------|
| 01 | `01_EDA_Theory.pdf` | EDA Theory | Covers concepts, steps, and best practices for performing EDA. |
| 02 | `02_EDA_Hands_On_Practical(DataPrep_Exploration).ipynb` | Hands-On Practice | Practice EDA techniques on sample datasets: cleaning, visualization, summary statistics. |
| 03 | `03_EDA_Hands_On_Practical_On_Heart_Disease.ipynb` | Heart Disease EDA | Apply EDA to a medical dataset, exploring features, distributions, and correlations. |
| 04 | `04_EDA_US_visa.ipynb` | US Visa EDA | Analyze US Visa dataset: trends, feature distributions, and insights. |


## Key Concepts Covered

- **Data Summarization:** Descriptive statistics, mean, median, variance, standard deviation.  
- **Data Cleaning & Preparation:** Handling missing values, duplicates, and inconsistent data.  
- **Visualization Techniques:** Histograms, boxplots, scatter plots, correlation heatmaps.  
- **Feature Exploration:** Relationships between features, feature importance, distributions.  
- **Project-Based EDA:** Real-world datasets like Heart Disease and US Visa for practical understanding.  



##  Learning Outcome

By completing these resources, learners will be able to:

1. **Understand dataset characteristics** and distributions before modeling.  
2. Perform **data cleaning, transformation, and preparation** for analysis.  
3. Apply **statistical summaries and visualization techniques** to extract insights.  
4. Conduct **feature exploration and correlation analysis**.  
5. Execute **project-based EDA** for real-world datasets.  



This folder serves as a **research-quality reference for EDA**, ensuring learners are fully prepared to move from **raw data to ML-ready datasets** with confidence.
