# Feature Engineering & Preprocessing Techniques

This folder contains **advanced feature engineering and preprocessing resources** for Machine Learning.  
It focuses on **encoding categorical variables, scaling and normalization, data transformations, and discretization**, preparing datasets for optimal model performance.

The folder includes **step-by-step Jupyter notebooks**, providing hands-on examples for each preprocessing technique.



## 📂 Folder & File Overview

| No | File / Notebook | Topic | Description / Learning Focus |
|----|----------------|-------|------------------------------|
| 01 | `01_One Hot Encoding & Dummy Variables.ipynb` | One-Hot & Dummy Encoding | Convert categorical variables into binary vectors for ML models |
| 02 | `02_LabelEncoder.ipynb` | Label Encoding | Transform categorical labels into numerical values |
| 03 | `03_OrdinalEncoder.ipynb` | Ordinal Encoding | Encode ordered categories while preserving ranking |
| 04 | `04_Mastering_Data_Scaling_Techniques.ipynb` | Feature Scaling | Min-Max, StandardScaler, RobustScaler, and scaling best practices |
| 05 | `05_Data_Transformation.ipynb` | Data Transformation | Log, square root, and custom transformations for skewed data |
| 06 | `06_L1 & L2 Normalization.ipynb` | Normalization | Normalize features using L1 and L2 norms for model training |
| 07 | `07_discretization.ipynb` | Discretization | Bin continuous variables into categorical intervals |



## 🔹 Key Concepts Covered

- **Encoding Categorical Variables:** One-Hot, Dummy, Label, and Ordinal encoding  
- **Feature Scaling:** StandardScaler, MinMaxScaler, RobustScaler, and normalization techniques  
- **Data Transformation:** Apply logarithmic, square root, and custom transformations  
- **Normalization:** L1 & L2 normalization for regression and distance-based models  
- **Discretization:** Convert continuous features to categorical bins for decision trees and other algorithms  


## Learning Outcomes

After completing these notebooks, learners will be able to:

1. Encode categorical variables appropriately for ML models  
2. Apply **feature scaling and normalization** to improve model performance  
3. Transform data to reduce skewness and handle non-linear relationships  
4. Perform **L1 and L2 normalization** for distance-based algorithms  
5. Discretize continuous features for feature engineering and modeling  



##  Recommended Workflow

1. Start with **categorical encoding** (One-Hot, Label, Ordinal)  
2. Move to **scaling techniques** to standardize numerical features  
3. Apply **data transformations** to correct skewed distributions  
4. Normalize features using **L1 and L2 norms**  
5. Discretize continuous variables where applicable  
6. Integrate all steps in a **complete preprocessing pipeline**  



This folder is designed as a **research-quality, hands-on resource**, preparing learners to **engineer and preprocess features for real-world Machine Learning workflows**.
